# Bulawayo Royal Construction (BRC)

> **"Do it right the first time and have peace of mind."**

Official responsive website for **Bulawayo Royal Construction**, a registered building contractor delivering architectural planning, turnkey residential/commercial construction, roofing, project management, and diaspora building oversight across Bulawayo and Zimbabwe.

---

## 🏗️ Features

- **Re-engineered Vector Brand Suite**: High-contrast, scalable SVG logos with Royal Navy (`#162866`) and Royal Gold (`#C8972E`) color tokens.
- **Interactive Project Portfolio**: 23 verified project cards across Foundations, Brickwork, Roofing, and 3D Architectural Plans with real-time category filtering and full-screen lightbox zoom.
- **Diaspora Building Desk**: Tailored transparent milestones, WhatsApp video inspections, and verified proof-of-delivery for overseas Zimbabweans.
- **Live Interactive Cost & Scope Estimator**: Instant estimation by project type, bedrooms, and finishes with direct WhatsApp quote dispatch.
- **Responsive Architecture**: Built with modern semantic HTML5, Vanilla CSS3 (zero gradients, clean design system), and lightweight Vanilla JavaScript.
- **Direct WhatsApp & Phone Reticulation**: Floating and inline dispatch to `+263 77 299 0134`.

## 🚀 Running Locally

To run the site locally using Python's built-in server:

```bash
python -m http.server 3456
```

Then visit [http://localhost:3456](http://localhost:3456) in your browser.
